# Sabor & Mais

Uma aplicação web desenvolvida com HTML, CSS e JavaScript, criada para apresentar o restaurante Sabor & Mais, com foco em qualidade, sabor e praticidade no atendimento aos clientes.

## Demonstração

[ Clique aqui para acessar o Sabor & Mais ](https://caique-torres.github.io/Sabor-Mais/)

## Funcionalidades

- Apresentação do restaurante
- Galeria de imagens
- Seção sobre o restaurante
- Cardápio com pratos e preços
- Filtros de pratos por categoria
- Carrinho de compras interativo
- Adição, remoção e alteração da quantidade de itens
- Cálculo automático do valor total do pedido
- Formulário com dados do cliente
- Opções de entrega ou retirada no local
- Campo para endereço e CEP
- Seleção da forma de pagamento
- Finalização do pedido pelo WhatsApp
- Links para aplicativos de delivery, como iFood, 99 e Keeta
- Seção de localização com mapa integrado
- Botões de contato integrados ao WhatsApp
- Menu responsivo para dispositivos móveis
- Layout responsivo
- Navegação entre seções da página
- Ano automático no rodapé

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (DM Sans e Playfair Display)
- Google Maps
- WhatsApp
- iFood
- 99
- Keeta

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, estilização de páginas, responsividade, navegação entre seções, manipulação do DOM, implementação de carrinho de compras e integração com o WhatsApp.
